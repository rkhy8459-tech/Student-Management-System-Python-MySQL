# Student Management System (Python & MySQL)

## 🎯 Project Overview
A modular, menu-driven **Student Management System** built using **Python** and **MySQL (XAMPP)** that allows users to perform real-time database operations seamlessly.

## 🛠️ Tech Stack
- **Language:** Python (`mysql-connector-python`)
- **Database:** MySQL (via XAMPP / phpMyAdmin)

## ✨ Key Features (CRUD Operations)
- **Insert:** Add new student records (Roll No, Name, Age, Course) directly into the MySQL database.
- **View:** Fetch and display all stored student records in real time.
- **Update:** Modify existing student details using their Roll Number.
- **Delete:** Remove student records safely from the database.
